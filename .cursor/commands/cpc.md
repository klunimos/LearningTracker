# CPC - Comment, Commit, Push

Run the following steps automatically:

1. **Stage all changes**: `git add .`
2. **Commit** with a descriptive message based on the changes (use `git status` and `git diff` to understand what was modified)
3. **Push** to the remote: `git push`

**Commit message rules:**
- **Always write in English** – commit messages are always in English.
- **Describe in detail** – explain what was changed (logic, purpose). Do not include file/class names – git shows the changed files.
